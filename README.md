# 整備見積アシスト(MVP)

車種・作業内容・整備士によって金額が変わる自動車整備の見積もりを、過去のExcel請求書・見積書を
少しずつ取り込みながら作れるようにするローカルWebアプリです。

**このMVPに含まれるデータはすべてサンプル(架空)です。** 実在の顧客・整備士・車両・金額とは
一切関係ありません。画面には常に「サンプル」タグで区別して表示されます。

## 特徴・できること

- 案件(車種・作業内容・整備士など)を入力すると、登録済みの過去事例から条件が近いものを
  提示します。完全一致でなくても「メーカー一致」「作業内容一致」などの根拠を示して候補を並べます。
  金額を自動で確定することはありません。
- 候補から選んだ事例の明細(部品代・工賃)を見積書の下書きにコピーし、そこから自由に編集できます。
- 小計・消費税・合計はその場で再計算されます。税率は設定画面で変更できます。
- 見積書は印刷(ブラウザの印刷機能でPDF保存可能)、専用のPDF出力、編集用Excel(.xlsx)出力に対応します。
- 参考事例がない案件は、整備士へ送る相談メモ(コピー用テキスト)を作成できます。回答内容・金額を
  記録し、後から「参考事例」として検索対象に加えられます。整備士へのメール等の自動送信はしません。
- Excel(.xlsx/.xls)・CSVを取り込めます。取り込み前に内容をプレビューし、どの列がどの項目
  (日付・車種・整備士・作業内容・金額など)に対応するかを自分で指定してから登録します。
  **元のファイルは読み取り専用で扱われ、一切変更・削除されません**(アップロードされたコピーのみを処理します)。
- 同じ内容のファイルを再度取り込もうとすると警告が表示されます(重複取り込み防止)。

## 動作環境

- Python 3.10以上(このマシンでは Python 3.14 で動作確認済み)
- 追加のインストール不要な標準ライブラリのみで動く軽量なWebアプリ(Flask)です。
- Node.js/npmは不要です。

## 初回起動方法

```bash
cd "<このフォルダ>"
python3 -m venv .venv
source .venv/bin/activate      # Windowsの場合: .venv\Scripts\activate
pip install -r requirements.txt
cd app
python3 -c "from db import init_db; init_db()"   # データベースを作成(初回のみ)
python3 seed_demo.py                              # サンプルデータを投入(任意・デモ用)
python3 app.py
```

ブラウザで `http://127.0.0.1:5001/` を開いてください。

2回目以降は、上記のうち `pip install` と `init_db` は不要で、次のコマンドだけで起動できます。

```bash
cd "<このフォルダ>/app"
source ../.venv/bin/activate
python3 app.py
```

サーバーを止めるときはターミナルで `Ctrl+C` を押してください。

## データの保存場所・バックアップ

- すべてのデータ(案件、見積、設定など)は `data/app.db` という1つのSQLiteファイルに保存されます。
- 取り込んだExcel/CSVの「コピー」は `uploads/` フォルダに保存されます(取り込み元の元ファイルには
  一切触れません)。
- **外部サーバーへの送信は一切行いません。** すべてこのPC内だけで完結します。AI API連携、
  クラウド保存、アクセス解析などの外部通信は組み込んでいません。
- バックアップは `data/app.db` と `uploads/` フォルダを丸ごとコピーしてください。これだけで
  すべてのデータが復元できます。

## Excel/CSV取り込みの対応状況

- 対応形式: `.xlsx` / `.xls` / `.csv`
- **非対応**: `.xlsm`(マクロ有効ブック)、`.xlsb`、ODS形式、画像スキャンのPDFなど。
  非対応形式は取り込み画面にその旨を表示し、代わりに「案件を手入力で登録」から基本情報と
  合計金額だけを手入力で登録できます。
- マクロや外部リンクは実行しません(読み取り専用でセルの値のみを読み込みます)。
- 現在のMVPは **1行=1案件** として取り込みます。1つの案件に複数の明細行がまたがる形式の
  帳票は、現状では「合計金額のみを割り当てる」運用になります(将来の改善余地として、
  グループ化キー列を指定して1案件に複数明細をまとめる機能は未実装です)。

## 今回のMVPで意図的に含めていない機能

- 複数人同時利用・ログイン・クラウド同期
- 金額の自動確定(参考事例の金額はあくまで「候補」であり、採用するかどうかは利用者が判断します)
- 整備士への自動送信(相談メモは手動でコピーして送付する前提です)
- すべてのExcel帳票を無確認で完全自動変換する機能
- 実在する取引先・整備士・価格の再現(すべてサンプルは架空です)

## 実施した確認作業

- Flask開発サーバーを起動し、以下の画面がすべて200 OKで表示されることを確認:
  見積もり作成・過去案件・相談メモ・Excel取り込み・設定。
- 案件を入力→参考事例が「一致条件」付きで候補表示→採用→明細反映→小計/税/合計の
  再計算(¥123,000 + 消費税10% = ¥135,300)が正しく行われることを確認。
- 見積書の印刷プレビュー(HTML)、PDF出力(日本語フォント込み)、編集用Excel出力(.xlsx)が
  いずれも正常に生成されることを確認。
- Excel取り込み: サンプルのxlsx(見出し行が2行目にある想定の乱れた表)をアップロードし、
  シート選択→プレビュー→列の割り当て→登録の一連の流れで3件の案件が正しく登録されることを確認。
  同一ファイルの再取り込み時に重複警告が出ることを確認。取り込み前後で元ファイルのMD5
  ハッシュが変わらない(＝元ファイルが一切変更されていない)ことを確認。
- 参考事例が見つからない案件について、相談メモ作成→整備士回答の記録→見積への反映→
  「整備士確認済み」の参考事例としての保存、という一連の流れが動作することを確認。
- Flaskサーバーを再起動し、登録した案件・見積・相談メモがすべて保持されている(SQLiteに
  永続化されている)ことを確認。

## 未対応・未確認の点(引き継ぎ事項)

- 実際の見積書ひな形・会社ロゴなどは未提供のため、汎用レイアウトのみを用意しています。
  実際のひな形を頂ければ、印刷・PDF・Excelのレイアウトを合わせて調整できます。
- 1案件に複数の明細行が分かれているExcel帳票の自動グループ化は未実装です(上記参照)。
- .xlsm(マクロ有効ブック)の取り込みは非対応です。該当ファイルがある場合は、事前に
  値のみのxlsxとして保存し直すか、手入力登録をご利用ください。
- 大量データ(数千件超)でのパフォーマンスは未検証です。
- 複数ユーザーでの同時アクセス(排他制御)は考慮していません(単一利用者・単一PCでの
  利用を前提としています)。
